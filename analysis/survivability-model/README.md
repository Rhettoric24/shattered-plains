# Generated Survivability experiment data

Regenerate with `npm run balance:survivability`. Read the concise evidence in [the focused report](../../docs/audits/SURVIVABILITY_MODEL_EXPERIMENT.md).

`results.csv` contains aggregate results only. Rate/probability/share columns are fractions, except `casualtyPercent`, which is a percentage. Blank values mean undefined or absent (for example, no starting Spearmen, or a Power ratio with zero own Power). `nominalWinnerSide` is blank because these scenarios supply controlled scalar opposition, not simulated opposing armies. Each scenario/model row is one army evaluated over its recorded replication range.

The manifest records the source revision before report creation and hashes of the actual working source files used. It also records the four unchanged models and evaluation counts. No generation timestamps or individual-seed logs are included. The broad combat baseline remains separate and unchanged.
