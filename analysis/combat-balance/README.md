# Generated combat balance snapshot

`results.csv` contains aggregate results, not individual seed records. `manifest.json` records exact parameters, counts, seed schedule and source hashes.

Regenerate with `npm run balance:combat`. Human-readable report: `docs/audits/COMBAT_BALANCE_BASELINE.md`. Source and usage: `combat-balance/README.md`.

Keep experimental scratch runs in a separate `--out` directory. Nothing in this directory is published by the static-site build or consumed by gameplay.
