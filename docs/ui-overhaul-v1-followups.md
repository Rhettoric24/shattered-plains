# UI Overhaul V1 follow-ups

These ideas were intentionally kept outside the structural V1 pass so the navigation work would not force new game mechanics or speculative data migrations.

- Plateau naming: preserve a persistent original/Parshendi name and optionally add an Alethi/common nickname. The intended presentation is an original identity such as `Nar Shaleth`, followed by a player-facing epithet such as `“The Crown”`. This needs a deliberate schema, naming-content, moderation, and migration design before implementation.
- Dynamic theme: retain hooks for future world-pressure presentation, but do not equate Hostility with Odium or couple Shard alignment to Hostility mechanics.
- Narak: the Shattered Plains navigation can accept a fourth activity later, but V1 does not expose or implement it.
- Army formations and saved presets: recruitment and contextual mission composition remain the current model. Persistent formations should only be introduced with a real management mechanic.
- Final visual finesse: perform after hands-on PWA playtesting of the new hierarchy, especially Ledger density, compact cards, and bottom navigation.
